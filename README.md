# LaserLive — Студия лазерной эпиляции

Статический сайт студии лазерной эпиляции в г. Вязьма.

## 📁 Структура проекта

```
laserlive/
├── index.html              ← главная страница (только разметка)
├── robots.txt              ← правила индексации для поисковиков
├── sitemap.xml             ← карта сайта для Google и Яндекса
├── README.md               ← этот файл
│
├── css/                    ← стили (порядок подключения важен!)
│   ├── reset.css           ← сброс стилей браузера
│   ├── variables.css       ← цвета, шрифты, тени (дизайн-токены)
│   ├── base.css            ← типографика и фон сайта
│   ├── animations.css      ← все @keyframes
│   ├── components.css      ← кнопки, карточки, формы, FAQ, табы
│   └── layout.css          ← навигация, секции, респонсив
│
├── js/                     ← скрипты (по одному файлу на задачу)
│   ├── preloader.js        ← заставка при загрузке сайта
│   ├── nav.js              ← мобильное меню + тень при скролле
│   ├── tabs.js             ← переключение прайса (Ж/М/Комплексы)
│   ├── faq.js              ← аккордеон вопросов
│   ├── reveal.js           ← появление секций при скролле
│   ├── counters.js         ← анимация счётчиков-достижений
│   ├── parallax.js         ← параллакс фоновых блобов
│   ├── active-nav.js       ← подсветка активного пункта меню
│   ├── confetti.js         ← взрыв конфетти при отправке заявки
│   ├── calculator.js       ← калькулятор стоимости курса
│   ├── reviews.js          ← карусель отзывов
│   └── form.js             ← форма заявки → WhatsApp
│
└── assets/
    └── images/             ← положи сюда фото, og-image и favicon
```

## ⚙️ Где менять что

### 🎨 Поменять цвета сайта
`css/variables.css` — все цвета в одном месте. Меняешь `--pink-500` — меняется по всему сайту.

### 📞 Поменять телефон
Сейчас номер `+7 (920) 660-94-70`. Меняй в **трёх** местах:

1. **`index.html`** — найди `79206609470` (через Ctrl+F) — там 3 вхождения: телефон, WhatsApp-ссылка, плавающая кнопка
2. **`index.html`** — также найди `+7 (920) 660-94-70` — текст для отображения
3. **`js/form.js`** — переменная `WHATSAPP_PHONE` в начале файла
4. **`index.html`** — в блоке `<script type="application/ld+json">` строка `"telephone": "+7-920-660-94-70"` (это для SEO)

### 📍 Поменять адрес
В `index.html` ищи «Вязьма» — там и в meta-тегах, и в JSON-LD, и в секции контактов.

### 💰 Поменять цены
Все цены в `index.html` в секции `<section id="prices">`. Каждый пункт — это `<div class="price-item">`.

### 🔢 Поменять цифры счётчиков
В `index.html` ищи `<section id="stats">`. У каждого числа есть атрибут `data-target="120"` — это число до которого будет накручиваться счётчик. Меняешь его — меняется анимация. `data-suffix="+"` добавляет «+» в конце.

### 📍 Поменять адрес на карте
В `index.html` найди `<div class="contact-map">`. В iframe сейчас стоит `oid=25308369377` — это ID твоей карточки «Laser Live» в Яндекс.Бизнесе. Если переедешь или сменишь карточку — открой свою новую страницу на Яндекс.Картах, скопируй ID из URL и подмени.

### 📝 Поменять отзывы
Сейчас в секции `<section id="reviews">` стоят 6 примеров-заглушек. **Замени их на реальные** с твоей страницы Яндекс.Карт: https://yandex.ru/maps/org/laser_live/25308369377/reviews/

Каждый отзыв — блок `<article class="review-card">`. Меняй:
- Текст отзыва внутри `<p class="review-text">`
- Первую букву имени в `<div class="review-avatar">А</div>`
- Имя клиентки в `<div class="review-meta-name">`
- Дату/источник в `<div class="review-meta-date">`

Можешь добавлять/удалять карточки — карусель сама подстроится.

### 🧮 Поменять зоны в калькуляторе
В `<section id="calc">` каждая зона — `<label class="calc-option">` с атрибутами:
- `data-zone="Лоб"` — название (попадёт в WhatsApp при отправке)
- `data-price="350"` — цена

Цены поменял → расчёт автоматически пересчитается.

### 📝 Поменять тексты услуг
Меняй прямо в `index.html` — там вся текстовка.

## 🚀 Запуск (для разработки)

Просто открой `index.html` в браузере — всё работает. Никаких сборщиков, npm, build не нужно.

Чтобы протестировать на телефоне через локальную сеть — можно запустить простой сервер:

```bash
# Если есть Python 3
python3 -m http.server 8000

# Если есть Node.js
npx serve
```

Затем открой `http://[ip-компьютера]:8000` с телефона в той же Wi-Fi сети.

## 🌐 Деплой на хостинг

1. Купи домен (например на reg.ru — 300 ₽/год)
2. Купи хостинг (Beget — от 150 ₽/мес)
3. Загрузи **всю папку `laserlive/`** в директорию `public_html` хостинга через файловый менеджер или FTP
4. Включи SSL (бесплатно у любого хостера, кнопка в панели)
5. Открой свой домен — должно работать

## 🔍 SEO — следующие шаги

После того как сайт открывается по своему домену:

1. **Яндекс.Вебмастер** — `webmaster.yandex.ru` → добавить сайт → подтвердить через мета-тег (раскомментируй строку в `index.html`) → загрузить `sitemap.xml`
2. **Google Search Console** — `search.google.com/search-console` → то же самое
3. **Яндекс.Бизнес** — `business.yandex.ru` → создать карточку студии с адресом, фото, прайсом (это даст основной трафик из Яндекс.Карт)
4. **Google Business Profile** — `business.google.com`
5. **2GIS** — добавить организацию бесплатно

**Самое важное для бьюти-сферы в маленьком городе** — карточки на Яндекс.Картах, 2GIS и Google Maps. Сайт нужен как «лицо», но 80% трафика приносят карты + отзывы.
